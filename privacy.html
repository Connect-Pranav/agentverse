Sunverse Studio — Privacy Policy

Sunverse Studio is a private tool used by the Sunverse music channel to prepare and upload its own videos to its own YouTube channel. It is not offered to the public.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos and read the channel's own analytics and comments. It does not access any other person's account.

What it stores

Access tokens are kept only as private secrets in the owner's own hosting accounts. No data is sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google Account permissions page (myaccount.google.com/permissions).
